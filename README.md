# Word Frequency Counter

A Python command-line tool that prints the most common words in a text file.

## Usage

python3 word_counter.py sample.txt
python3 word_counter.py sample.txt 5

## How it works

1. Reads the file
2. Lowercases and splits the text into words
3. Strips punctuation
4. Counts words in a dictionary
5. Sorts and prints the top N
